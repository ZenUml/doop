# Keep pages inside diagrams

On 2026-11-13 the owner chose Document → Board → Diagram → Page. Legacy pages must remain inside one imported diagram; flattening each legacy page into a separate board and diagram loses that boundary even when source text survives. The outer workspace uses the name Board, while existing internal canvas-page protocol identifiers remain compatible. Diagram page source, styles, active selection and recovery inputs travel together through editing, history, backup and restore.
